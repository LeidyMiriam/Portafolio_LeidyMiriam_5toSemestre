# Portafolio · La Biblioteca

Portafolio del semestre hecho en **React** con una escena 3D gótico-romántica:
una habitación de noche con una ventana ojival donde llueve y caen relámpagos,
un escritorio iluminado por velas (pergamino a medio escribir, pluma, tintero, lentes)
y una estantería con novelas oscuras. Los libros de **lomo dorado** son los proyectos.

## Cómo correrlo

```bash
npm install
npm run dev      # abre http://localhost:5173
npm run build    # compila y deja la página lista en la raíz (index.html, assets/, proyectos/)
```
